# Histórias de Usuário

| ID | História | RF | Prioridade |
|---|---|---|---|
| US-01 | Como usuário que encontrou um objeto perdido, quero cadastrá-lo no sistema para que o dono possa localizá-lo e recuperá-lo. | RF-01 | Must |
| US-02 | Como usuário do sistema, quero consultar os objetos perdidos e encontrados registrados para tentar encontrar meu objeto perdido. | RF-03 | Must |
| US-03 | Como usuário do sistema, quero filtrar e pesquisar para procurar apenas os itens de interesse. | RF-05, RF-06 | Should |
| US-04 | Como usuário que perdeu um item, quero solicitar a devolução do objeto encontrado de forma que ele seja entregue à pessoa certa. | RF-04, RF-07 | Must |
| US-05 | Como usuário que perdeu um item, quero cadastrá-lo como perdido para que outro usuário possa identificá-lo caso o encontre. | RF-02 | Must |
| US-06 ‡ | Como usuário, quero me autenticar para usar o sistema com segurança. | RF-09 | Must |
| US-07 ‡ | Como quem cadastrou um objeto encontrado, quero analisar as solicitações de devolução para entregar o item só a quem comprovar a posse. | RF-10 | Must |
| US-08 ‡ | Como responsável por um objeto, quero ser avisado de novas solicitações para responder rapidamente. | RF-08 | Could |

Os critérios de aceite de cada história estão nos RFs correspondentes em `requisitos-funcionais.md`. US-01 a US-05 seguem a numeração do backlog.
